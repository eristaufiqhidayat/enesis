# Loading Barang mengisi tinggi layar dengan header tetap

## Ringkasan

Aktifkan `tinggi_penuh` pada halaman `loading_barang` di `config/marketama.php`, sehingga tabel `loading_barang` memakai area scroll sendiri dan header kolomnya menempel saat digulir.

## Kriteria Selesai

- Di `/loading_barang` dengan banyak baris, header kolom tetap terlihat saat tabel digulir, dan judul serta pencarian tidak ikut bergerak.
- Catatan jumlah data dan pagination di footer kartu tetap terlihat tanpa menggulir halaman.
